# Duarte · Staff de SuperCraft

Página de perfil de staff de Duarte, incluida en el repositorio del portafolio y publicada en https://duartedev.lat/staff/.

## Archivos

- `index.html`: contenido y script del fondo.
- `style.css`: estilos.
- `privacidad.html`: aviso de privacidad.
- `og-image.png`: imagen que aparece al compartir el enlace.

## Cómo publicarla

La publicación se configura una sola vez desde la raíz del repositorio: Settings → Pages → Deploy from a branch → `main` → carpeta `/ (root)`. El dominio personalizado se configura en el `CNAME` de la raíz; no agregues un `CNAME` dentro de esta carpeta.

El `404.html` de la raíz cubre las direcciones que no existen en el sitio.
