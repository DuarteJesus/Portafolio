# Portafolio · Duarte Jesús

Sitio estático (HTML + CSS + JS, sin build).

- **Edita tu info:** `js/config.js`
- **Páginas:** `/`, `/staff/`, `/dashboard/`, `/privacidad.html`, `404.html`
- **Despliegue:** súbelo a la raíz de Netlify, Vercel, Cloudflare Pages o GitHub Pages (con dominio propio). `404.html` se usa automáticamente.
- **Discord en vivo:** entra al servidor de Lanyard (discord.gg/lanyard) con tu cuenta para que tu estado sea público.
- **Formulario:** sin `contactEndpoint` abre tu app de correo; para envío directo usa Formspree u otro servicio y pega su URL.

> **Probar en local:** no abras `index.html` con doble clic para las subpáginas; usa un servidor (`python3 -m http.server` o la extensión Live Server de VS Code) y entra a http://localhost:8000
