# Portafolio de Duarte

Página personal de Duarte con sus proyectos y habilidades como programador junior.
Publicada en https://duartedev.lat/ con GitHub Pages.

## Archivos

- `index.html`: contenido y script del fondo.
- `style.css`: estilos.
- `CNAME`: dominio personalizado (`duartedev.lat`). No lo borres.
- `sitemap.xml` y `robots.txt`: para buscadores.
- `privacidad.html`: aviso de privacidad.
- `404.html`: página que se muestra cuando una dirección no existe.
- `og-image.png`: imagen que aparece al compartir el enlace.
- `img/` y `Proyectos/`: tu foto y los .zip de los proyectos (súbelas tú).

## Cómo publicarla

Settings → Pages → Deploy from a branch → `main` → carpeta `/ (root)`.
