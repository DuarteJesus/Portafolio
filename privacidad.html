TRANSPARENCIA · DATOS Y PRIVACIDAD

Aviso de privacidad

Última actualización: octubre de 2026.

Quién es el responsable

Este sitio es personal y lo administra Duarte, desde Colombia. Para cualquier consulta sobre tus datos, escríbeme desde la sección de contacto de mi portafolio: duartedev.lat.

Qué datos recojo

El formulario permite enviar un mensaje sin correo ni cuenta. El nombre es opcional; no se solicita ni se almacena el correo de quien escribe. Los mensajes se guardan en Supabase hasta que Duarte los elimine desde la dashboard privada.

Dónde está alojado

El sitio se publica con GitHub Pages y usa Supabase para el formulario, la autenticación de la dashboard y las métricas agregadas. La biblioteca de Supabase se carga desde jsDelivr. GitHub, Supabase y jsDelivr pueden procesar datos técnicos de conexión según sus propias políticas; la aplicación no guarda direcciones IP, user agents ni referentes de visita.

Métricas de visitas

Para contar vistas y sesiones activas se crea un identificador aleatorio temporal en el almacenamiento de sesión del navegador. No se usa para conocer tu identidad. Los identificadores de sesiones inactivas se eliminan cuando llega una nueva visita después de 30 días; los totales diarios agregados se conservan para mostrar el historial. El contador no recopila nombres, IP, user agents ni las páginas de referencia.

Mensajes

Los mensajes y, si decides proporcionarlo, tu nombre se muestran únicamente en una dashboard protegida para Duarte. No incluyas información sensible en el formulario. Puedes solicitar la eliminación de un mensaje desde el contacto del portafolio.

Enlaces a otros sitios

Este sitio enlaza a redes y servicios externos, como GitHub, Instagram, TikTok, YouTube, Discord, NameMC y SuperCraft. Supabase también presta servicios de base de datos y autenticación. Cada proveedor tiene sus propias políticas de privacidad, que se aplican al usar sus servicios.

Tus derechos

Según la Ley 1581 de 2012 de Colombia, puedes conocer, actualizar y rectificar tus datos personales, y pedir que se eliminen. Si me escribiste y quieres ejercer alguno de estos derechos, contáctame por el enlace de arriba.

Cambios

Si cambia el tipo de información recogida o la forma de usarla, actualizaré este aviso.
